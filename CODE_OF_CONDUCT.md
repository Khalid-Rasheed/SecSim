# Contributor Covenant Code of Conduct (summary)

SecSim welcomes everyone. In addition to the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
— which we adopt in full (respectful communication, no harassment, scope
limited to project spaces, enforcement via maintainers) — project-specific
rules apply:

1. **Teaching crypto ≠ endorsing weak crypto.** Never present toy
   parameters as production-safe, in code, UI copy, or reviews.
2. **Review kindly, merge strictly.** CI must be green; bilingual strings
   and tests are non-negotiable for user-facing changes.

Violations: contact the maintainers privately (see SECURITY.md for the
private channel). Repeated or severe violations lead to removal from the
project spaces.
