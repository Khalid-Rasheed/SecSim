# Security Policy

## Scope note (please read first)

SecSim **intentionally** ships weak cryptography for teaching (toy RSA keys,
simplified AES key handling, MD5, Caesar). These are documented features,
not vulnerabilities — do not report them.

## Reporting a real vulnerability

- **Do not open a public issue.** Contact the maintainers privately via a
  GitHub private vulnerability report
  (Security tab → Report a vulnerability) or the email listed on the
  maintainer profile.
- Include: affected endpoint/file, impact, and a minimal reproduction.
- We aim to acknowledge within 72 hours and will credit reporters (unless
  anonymity is requested) in the release notes.

## Supported versions

Only the latest `master` is supported with security fixes.
